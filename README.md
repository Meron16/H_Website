# Hirearky — frontend redesign

Modern redesign of [hirearky.com](https://hirearky.com/) built with Vite, React, TypeScript, Tailwind CSS, and GSAP.

## Brand constraints

- Keeps Hirearky’s purple palette (`#936DFF`, `#6941C6`, `#42307D`, `#F9F5FF`)
- No people photography — abstract talent-network visuals only

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://localhost:5174/`).

## Build

```bash
npm run build
npm run preview
```

## Pages

- `/` — Home
- `/about` — About + FAQ
- `/contact` — Contact form (opens mail to `hello@hirearky.com`)
- `/blogs` — Blog teasers placeholder
